# SingleHtmlEditor

SingleHtmlEditor 是一个可离线使用的单文件阅读器。打开本地文件夹后，可浏览 Markdown、代码、图片、音视频、PDF、Office、EPUB 等常见文件，并支持文本编辑写回。

## 开始使用

- 启动后显示欢迎页，可打开文件夹、选择文件、查看使用说明或恢复最近文件夹。
- 点击「打开文件夹」选择要阅读的目录；Chrome / Edge 会请求一次读取权限。
- 也可以把文件夹或文件直接拖入窗口。
- 左侧活动栏提供资源管理器、快速打开、使用说明和主题切换；侧栏折叠后活动栏仍保留。
- 单击文件会在顶部的斜体预览标签中打开，再次单击其他文件会复用该标签；双击文件可固定标签。
- 标签可切换和关闭；进入编辑模式会自动固定当前标签；关闭最后一个标签后回到欢迎页，文件树仍会保留。
- 使用说明是独立的可关闭标签，不计入文件数，也不会出现在文件树或快速打开列表中。
- 切换标签会保留该标签的未保存草稿、编辑位置和视图设置；有草稿的标签显示圆点。
- 关闭含未保存修改的标签、切换文件夹前会先确认；草稿只保存在当前页面内存中，刷新后不会恢复。
- 未保存草稿总文本上限为 20M 字符，超过时需先保存或取消部分标签的修改。
- 文件只在当前浏览器本地读取，不会上传，也不需要联网。
- 编辑文本时按 `Ctrl+S` 保存，写回原文件前会再请求写入权限。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+P` | 快速打开文件（`Enter` 预览，`Ctrl+Enter` 固定） |
| `Ctrl+B` | 切换侧栏 |
| `Ctrl+E` | Markdown 源码 |
| `Ctrl+S` | 保存编辑 |
| `Alt+←` / `Alt+→` | 上一个 / 下一个文件 |
| `Esc` | 关闭浮层或退出编辑 |

## 离线说明

页面本身、README 和阅读功能均可离线使用。最近文件夹的权限确认是浏览器本地行为，不需要网络连接。

> 如果清除了站点数据，最近文件夹记录会一并删除；此时重新打开文件夹即可重新建立记录。
