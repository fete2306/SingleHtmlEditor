# SingleHtmlEditor

SingleHtmlEditor 是一个可离线使用的单文件阅读器。打开本地文件夹后，可浏览 Markdown、代码、图片、音视频、PDF、Office、EPUB 等常见文件，并支持文本编辑写回。

## 开始使用

- 点击「打开文件夹」，选择要阅读的目录；Chrome / Edge 会请求一次读取权限。
- 也可以把文件夹或文件直接拖入窗口。
- 单击文件会在顶部的斜体预览标签中打开，再次单击其他文件会复用该标签；双击文件可固定标签。
- 标签可切换和关闭；进入编辑模式会自动固定当前标签；关闭最后一个文件后回到欢迎页。
- 文件只在当前浏览器本地读取，不会上传，也不需要联网。
- 编辑文本时按 `Ctrl+S` 保存，写回原文件前会再请求写入权限。

## 最近文件夹

<div class="recent-panel" id="recent-panel"></div>

在支持目录句柄的浏览器（Chrome / Edge）中，本页会记住最近打开的 5 个文件夹名称和目录句柄。句柄保存在浏览器 IndexedDB 中，不记录绝对路径。

- 启动时会自动检查最近一次目录的授权状态。
- 权限仍然有效时，直接恢复到该文件夹。
- 权限需要重新确认时，停留在本说明页，并显示恢复列表；点击「恢复」一次即可重新授权。
- 浏览器不允许页面在启动时自动弹出文件系统授权框，因此首次恢复必须由用户点击触发。
- Firefox / Safari 等不支持目录句柄的浏览器仍可通过「打开文件夹」载入文件，但不保存最近目录。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+P` | 快速打开文件（`Enter` 预览，`Ctrl+Enter` 固定） |
| `Ctrl+B` | 切换侧栏 |
| `Ctrl+E` | Markdown 源码 |
| `Ctrl+S` | 保存编辑 |
| `Alt+←` / `Alt+→` | 上一个 / 下一个文件 |
| `Esc` | 关闭浮层或退出编辑 |

## 离线说明

页面本身、README 和阅读功能均可离线使用。最近文件夹的权限确认是浏览器本地行为，不需要网络连接。

> 如果清除了站点数据，最近文件夹记录会一并删除；此时重新打开文件夹即可重新建立记录。
